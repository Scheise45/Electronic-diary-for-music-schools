Техническое задание: Электронный дневник для музыкальных школ
1. Общие сведения
Название проекта: Электронный дневник для музыкальных школ
Тип: Веб-приложение
Назначение: Учёт оценок, домашних заданий и расписания в музыкальной школе
Платформа: MVP развёртывается на PythonAnywhere

2. Цель проекта
Создание простой, доступной и понятной системы для управления учебным процессом в музыкальной школе с разными ролями пользователей и поддержкой образовательных программ.


2. Роли пользователей
Входит в MVP:

Ученик / Родитель — только просмотр

Учитель — может выставлять ДЗ

Администрация — создаёт пользователей, управляет расписанием

После MVP:

Классный руководитель — учёт посещаемости и объявления
Учитель - выставление оценок и посещаемости

5. Функциональные модули (с указанием MVP)
Авторизация и вход — (MVP)

Оценки -  — (не входит в MVP)

Домашние задания — (MVP)

Расписание — (MVP)

Управление пользователями (админ) — (MVP)

Предметы и классы — (MVP)

Загрузка текстовых файлов (pdf, doc, txt) — (MVP)

API-интерфейс — (MVP)

Объявления — (не входит в MVP)

Посещаемость — (не входит в MVP)

Мобильная версия — (Bootstrap)

6. Стек технологий
Язык: Python 3
Бэкенд: Flask
БД: MySQL (через SQLAlchemy)
Фронтенд: HTML + Bootstrap
Хостинг: PythonAnywhere (для MVP)
Верстка: Адаптивная (Bootstrap)

7. Авторизация
Регистрация только через администрацию.
Логин генерируется по формуле: КККК_ИОФФФФФФГГ
Пароль создаётся автоматически и передаётся пользователю вручную.

8. Нефункциональные требования
Максимум пользователей одновременно: ~10 (на MVP-хостинге)

Кол-во аккаунтов в системе: до 1000

Поддержка устройств: ПК, планшеты, смартфоны

Язык интерфейса: Русский

Безопасность: Простой контроль доступа через сессию Flask

Резервное копирование: Ручное (SQL дамп по расписанию)

9. Развитие после MVP
Расширенная система ролей (куратор, методист)

Модуль загрузки учебных материалов

Статистика, графики, экспорт в PDF/Excel

Чат для родителей и учителей

Массовые уведомления

Поддержка WebSocket (при переносе на VPS)

10. API-интерфейс (Не входит в MVP)
Приложение предоставляет REST API для внешнего доступа и интеграции.

Возможности:

Получение расписания ученика/учителя

Получение списка предметов, классов и пользователей

Получение/отправка оценок и домашних заданий (с авторизацией)

Эндпоинты для администратора: создание и редактирование пользователей

Технологии:

Flask + Blueprint API-маршрутов

Аутентификация через токены (например, JWT или сессионный ключ)

Формат ответа: JSON

Пример запроса:
GET /api/schedule/5 → расписание для пользователя с id=5

11. Загрузка учебных материалов (Не входит в MVP)
Система должна позволять учителям прикреплять текстовые файлы к заданиям и/или предметам.

Поддерживаемые форматы:

.pdf

.txt

.doc / .docx

Функциональность:

Загрузка файла через веб-интерфейс (форма)

Хранение файлов на сервере (например, в каталоге /uploads)

Сохранение информации о файле в БД (имя, расширение, кто загрузил, когда)

Отображение списка файлов для учеников с возможностью скачивания

Удаление/редактирование доступно только автору или администратору

Ограничения:

Только авторизованные пользователи с ролью Учитель или Администратор могут загружать

Ученик может только скачивать, если имеет доступ к предмету

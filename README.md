# 🎵 Электронный дневник для музыкальных школ

Проект представляет собой веб-приложение, предназначенное для музыкальных школ России. Его цель — **цифровизация образовательного процесса**, создание современной, удобной платформы для взаимодействия учеников, родителей, преподавателей и администрации.

---

## 🚀 Основные возможности

- Разграничение прав доступа по ролям
- Учёт оценок, домашних заданий, посещаемости
- Учебные планы по программам обучения
- Автоматическая генерация логинов и паролей
- Расписание занятий
- Публикация объявлений
- REST API для внешних разработчиков (мобильное приложение и пр.)

---

## 👥 Роли пользователей

| Роль                   | Возможности |
|------------------------|-------------|
| 👨‍🎓 Ученик / Родитель  | Просмотр расписания, оценок, домашних заданий и объявлений |
| 👩‍🏫 Учитель            | Выставление оценок и домашних заданий **по своим предметам**, просмотр общей успеваемости учеников |
| 🧑‍🏫 Классный руководитель | Все права учителя + выставление **посещаемости**, публикация объявлений для закреплённых учеников |
| 🛠️ Администрация        | Управление расписанием, регистрацией, правами, данными, полная видимость всех разделов системы |

---

## 📘 Программы обучения

Система поддерживает следующие программы:

- **Предпрофессиональная программа (ППП)**
- **Общеразвивающая программа (ОРП)**

Каждая из программ имеет собственный перечень дисциплин, объём учебной нагрузки и срок обучения.
Нагрузка может различаться в зависимости от направления обучения (струнные, духовые и т.д.).

## 🔐 Регистрация и авторизация

Регистрация осуществляется **администрацией школы**. Для этого предоставляются:
- Номер телефона родителя
- Электронная почта родителя

После чего системе автоматически генерируются:
- **Логин**: `КККК_ИОФФФФФФГГ`
  - `КККК` — код школы
  - `ИОФФФФФФ` — инициалы + фамилия
  - `ГГ` — год зачисления
- **Пароль**: генерируется случайным образом, не задаётся вручную

## 📁 REST API

Проект включает в себя **REST API**, предназначенное для внешних разработчиков:

- Получение данных о расписании, учениках, оценках, посещаемости
- Интеграция с мобильными приложениями
- Возможность расширения функциональности платформы
